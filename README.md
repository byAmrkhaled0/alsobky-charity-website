# مؤسسة حسن السبكي الخيرية - موقع React/Vite

موقع عربي RTL احترافي لمؤسسة حسن السبكي الخيرية، مخصص لعرض:

- نبذة المؤسسة
- مسابقة آل سبكي للقرآن الكريم
- مسابقة وَرتِّل لأجمل أداء صوتي
- أكاديمية القرآن والعلوم الشرعية
- الاستعلامات والتسجيل
- التبرعات والتواصل
- معرض الصور والفائزين والشركاء

## التشغيل على VS Code

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```

## أهم الملفات

- `src/data/index.ts` لتعديل النصوص والأرقام والفائزين والشركاء.
- `src/components/Layout.tsx` للهيدر والفوتر وأزرار واتساب والرجوع للأعلى.
- `src/pages/Home.tsx` للصفحة الرئيسية.
- `src/pages/Competitions.tsx` لصفحة المسابقات والاستعلام.
- `public/images` لتغيير الصور.

## ملاحظات مهمة قبل النشر

- أسماء الفائزين والشركاء تم وضعها كأماكن مخصصة وليست أسماء حقيقية، ويجب استبدالها بالقوائم المعتمدة رسميًا.
- أزرار التسجيل والاستعلام مربوطة بالموقع الرسمي `alsobky.com`.
- روابط السوشيال الحالية:
  - Facebook: صفحة المؤسسة المرسلة.
  - Instagram: `alsobki_charity`.
