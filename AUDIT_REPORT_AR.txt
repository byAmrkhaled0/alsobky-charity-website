الفحوص المنفذة
==============
- فحص البناء الإنتاجي وملف الاستضافة.
- فحص جميع مراجع الصور داخل ملفات الموقع.
- استبدال 10 مراجع قديمة كانت تشير إلى صور غير موجودة.
- التأكد من وجود وصف بديل لجميع عناصر الصور.
- مراجعة ربط المسارات بالقائمة والتطبيق.
- مراجعة صور رصف طريق بطرة وتصنيفها ضمن خدمة المجتمع.
- مراجعة صور العام التاسع، مسابقة آل سبكي، ومسـابقة ورتّل.
- التأكد من ضغط الصور والحفاظ على حجم مناسب للتحميل.
- التأكد من وجود نسختي العرض العربية والإنجليزية في الصفحات الأساسية.
- مراجعة روابط فيسبوك وواتساب والتسجيل والاستعلام الموجودة في المحتوى.

ملاحظات تشغيلية
===============
- الموقع يستخدم React وTypeScript وTailwind CSS ضمن بيئة Vinext.
- التنقل الداخلي يعتمد على HashRouter، لذلك تظهر المسارات بعد علامة # في الرابط.
- نموذج التواصل السريع يفتح واتساب ولا يحفظ البيانات في قاعدة بيانات.
- روابط التسجيل والاستعلام الرسمية وروابط فيسبوك خارجية، وتظل صلاحيتها معتمدة على المواقع الأصلية.
- مجلد node_modules وملفات البناء المؤقتة غير موجودة داخل الملف المضغوط؛ تُثبت الحزم بأمر npm install.

طريقة التشغيل
============
1. فك ضغط الملف.
2. افتح Terminal داخل مجلد المشروع.
3. شغّل: npm install
4. للتطوير المحلي: npm run dev
5. لفحص النسخة الإنتاجية: npm run build
